# Lab 1: Viewing IPv4 Settings in Windows

## Goal
Use `ipconfig` to find the network settings Windows shows for this computer.

## Steps
1. Open the Windows Start menu and search for **Command Prompt**.
2. Open it and type `ipconfig`, then press Enter.
3. Find the active connection, such as Wi-Fi or Ethernet.

## What to look for
- **IPv4 Address:** the computer's address on its network.
- **Subnet Mask:** helps show which part of the address identifies the network.
- **Default Gateway:** the router address Windows uses to reach other networks.
